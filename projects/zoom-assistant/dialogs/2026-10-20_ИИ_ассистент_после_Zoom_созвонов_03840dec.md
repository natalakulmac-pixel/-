Ассистент написан, но целиком ещё не запускался: нет ключей. Я проверила только чтение транскрипта на тестовом примере, оно работает.

**Как будет работать:** раз в 15 минут программа проверяет облачные записи Zoom. Когда у записи появится расшифровка, Claude (модель Opus 5.5) сделает из неё 4 сообщения в Telegram: резюме, задачи («кто — что — срок»), письмо участникам и идеи для постов. Ещё придёт файл со всеми итогами, его копия сохранится в папку `итоги`. Созвоны короче 5 минут пропускаются, и одна встреча дважды не придёт.

Если Claude откажется обрабатывать запрос, он автоматически передаст его другой модели.

**Что нужно от вас** (по шагам в [README.md](README.md)):
1. **Zoom:** включить облачную запись и расшифровку записи («Аудиотранскрипт»), затем создать приложение типа Server-to-Server OAuth и взять из него 3 ключа. Нужен платный тариф Zoom.
2. **Claude:** ключ на console.anthropic.com, на счету должны быть деньги.
3. **Telegram:** создать бота через @BotFather.
4. Скопировать `.env.example` в `.env` и вписать туда ключи.

Потом проверка на тестовом созвоне:
```bash
python assistant.py --file sample.vtt
```
И запуск по расписанию:
```bash
powershell -ExecutionPolicy Bypass -File setup_task.ps1
```

Работает, только пока компьютер включён. Как пройдёте шаги, пришлите итог тестового запуска, вместе всё проверим.

Файлы в папке `zoom-assistant`:
- [assistant.py](assistant.py) — сам ассистент
- [setup_task.ps1](setup_task.ps1) — запуск каждые 15 минут
- [sample.vtt](sample.vtt) — тестовый созвон
- [README.md](README.md) — инструкция
